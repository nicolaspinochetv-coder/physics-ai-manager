1. Read `.ai/CORE.md`.
2. Read `.ai/PROJECT_CONTEXT.md`.

5. Read only the canonical state files relevant to the current task.
6. Read `.ai/HANDOFF.md` only when continuing an actual handoff from another agent/session.
