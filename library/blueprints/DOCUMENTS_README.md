# Documents

This folder is a shared staging area for reference material the user supplies directly — prior literature, datasets, specs, correspondence, or any other file worth keeping alongside the project. It exists regardless of which modes are installed.

Files land here in one of two ways:

- copied in through the desktop app (New Project or Manage Project → "Import documents");
- placed here manually by the user or an agent.

## For agents

A file appearing in `documents/` is **not yet catalogued**. Landing here only means the bytes exist in the project; it carries no claim that the content has been read, verified, or judged relevant.

At the start of a task, if `documents/` contains files not yet referenced from any canonical file (`research_literature.md`, `paper/claims_sources.md`, `learning/concept_map.md`, `PROJECT_CONTEXT.md`, or similar, depending on the active mode):

1. inspect enough of each file to identify what it is;
2. if it is genuinely relevant to the current work, add a proper entry to the active mode's canonical literature/notes file, following the literature discipline in `.ai/CORE.md`;
3. if it is not relevant to the active mode, leave it in place rather than deleting it — another mode or a later task may still need it;
4. never claim a source supports a scientific statement without having actually inspected it, regardless of how it arrived in the project.

Do not delete or move files out of `documents/` merely to appear organized. This folder is allowed to contain material that has not been triaged yet.
