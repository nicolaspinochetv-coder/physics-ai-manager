# Start Here

This folder is the reusable **Physics AI Master library**, not a scientific project workspace.

To create or extend a project with a filesystem-capable AI agent, tell it:

> Read `INITIATE.md` in this folder and follow it to deploy my Physics AI project.

The initiator will ask for the project type, target AI environment, and destination, then use the deterministic deployer. Project-specific rules belong in the deployed project's `.ai/PROJECT_CONTEXT.md`; do not edit the deployed managed copies of `CORE.md` or mode blueprints.
